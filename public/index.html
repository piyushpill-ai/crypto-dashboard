BTC/AUD Spread Dashboard

Live bid/ask across Australian exchanges with public APIs.
—
Effective price = the volume-weighted average fill price to buy the entered A$ amount, obtained by walking each venue's ask order book, × (1 + taker fee). For retail brokers with no public order book it is the quoted ask × (1 + fee), or the quote as-is where the fee is baked in (Swyftx). Small amounts fill at top-of-book; larger amounts include slippage. Depth charts and slippage tiles (A$1k/10k/100k) use live order-book data, so retail brokers show no depth. Winner = lowest effective price for the entered amount. Samples collected every 4h via GitHub Actions and committed to data/samples.csv in the repo.
